# Mahiya Edge — Setup & Deployment

## Requirements

- [Node.js](https://nodejs.org) v18+
- [Python](https://python.org) 3.9+
- [Git](https://git-scm.com)

---

## Quick Start (Any Machine)

### 1. Clone & install

```bash
git clone <your-repo-url>
cd MAHIYA
npm run setup
```

This installs all Node dependencies and builds the frontend into `backend/public`.

### 2. Configure environment

```bash
cp backend/.env.example backend/.env
```

Edit `backend/.env` and set at minimum:
- `CLINIC_PIN` — the PIN users enter to access the app
- `GEMINI_API_KEY` — get free at https://aistudio.google.com/app/apikey
- `DB_ENCRYPTION_KEY` — any 32+ character string

### 3. Install Python dependencies

```bash
pip install google-generativeai faster-whisper faiss-cpu sentence-transformers
```

### 4. Build the RAG index

```bash
python rag/build_index.py
```

### 5. Start the app

```bash
NODE_ENV=production npm start
```

Open http://localhost:3001 — the full app runs from a single process.

## True Offline AI (Ollama)

For fully offline Gemma 4 inference with no API key needed:

```bash
# Install Ollama: https://ollama.com
ollama pull gemma3n
ollama serve
```

The app auto-detects Ollama. Priority: Ollama → Gemini API → Keyword fallback.

```bash

# Terminal 2

```

```bat

copy backend\.env.example backend\.env
:: Edit backend\.env with your values

```

## Folder Structure

```
MAHIYA/
├── backend/        # Express API + SQLite (serves frontend in production)
│   └── public/     # Built frontend (auto-generated by npm run build)
├── frontend/       # React source (dev only)
├── ai/             # Gemma 4 inference (analyze.py, transcribe.py)
├── rag/            # FAISS index + retriever
├── guidelines/     # Clinical reference documents
├── database/       # Encrypted SQLite file (auto-created)
└── prompts/        # Prompt templates
```

## AI Inference Modes

| Mode | Requires | Speed | Quality |
|------|----------|-------|---------|
| Ollama (local) | Ollama + `gemma3n` pulled | Slow on CPU | Best |
| Gemini API | `GEMINI_API_KEY` | Fast | Best |
| Keyword fallback | Nothing | Instant | Basic |

Check active mode at: http://localhost:3001/api/ai/status
